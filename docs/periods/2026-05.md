# May 2026 — foundation

## What changed

- Established the RLM-oriented reproduction loop: ingest, understand, plan,
  implement, execute, verify, and report.
- Built the initial lab/leaderboard UI and file-backed run artifact contract.
- Added local, Docker, and RunPod execution foundations, plus early GPU
  reservation and capacity checks.
- Added rubric/metric safeguards after failures where placeholder, stale, or
  incomplete experiment data could look like a legitimate result.

## Decisions that still matter

- The harness owns execution safety: environment setup, resource selection,
  distributed launch, and final artifact layout must not depend on an agent
  improvising them correctly.
- Multi-GPU memory relief means sharding (FSDP/ZeRO), not DDP replication.
- A quick smoke test is never sufficient evidence for a scored reproduction.
- The latest observed experiment metrics, not a remembered or hand-filled
  summary, are the grading input.

## Resulting boundaries

- `backend/agents/rlm/` owns orchestration and evidence flow.
- `backend/services/runtime/` owns execution transports.
- `runs/<id>/` owns durable run state; the API and UI are readers/writers of
  that state, not its authority.
